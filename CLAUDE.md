# Ello GTM Context OS

## Company
Ello (https://ello.africa/): to fill in after research.

## How this folder works
- `.claude/skills/`: reusable Claude skills for GTM tasks. Read when a task matches a skill.
- `context/icp/`: ideal customer profile, personas, signals. Read before targeting or list building.
- `context/positioning/`: value proposition, positioning, competitors. Read before writing any pitch or comparison.
- `context/messaging/`: messaging framework and approved facts. Read before writing any copy.
- `context/brand-kit/`: voice, tone, visual rules. Read before writing or designing anything public.
- `context/docs/`: reference docs (case studies, GTM system). Read for depth on how Ello sells.
- `context/docs/research/`: raw, sourced research on Ello and its market. Read when a context doc needs a source.
- `knowledge-base/playbooks/`: repeatable how-tos and templates. Read before running a workflow.
- `knowledge-base/learnings/`: what worked and what did not. Read before planning a new campaign.
- `meetings/`: meeting notes and transcripts. Read when a decision or request needs its origin.
- `output/campaigns/`: finished campaign assets and copy. Write here; read to reuse past work.
- `tools/`: scripts and tool configs. Read when a task needs automation.
- `weekly-priorities/`: one file per ISO week (YYYY-Www.md). Read at the start of every session.
- `work-log/`: one file per ISO week, timestamped entries. Write after every change.

## Rules
- Cite a source for every company fact.
- Never invent numbers.
- No em dashes in any copy.
- Ask before sending or publishing anything.
- Log every change in this week's work log (`work-log/YYYY-Www.md`).
