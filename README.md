# Ello GTM Context OS

The go-to-market workspace for [Ello](https://ello.africa/), a call and chat based AI agent for African SMEs.

It holds the sourced context (ICP, positioning, messaging, brand), playbooks, learnings, meeting notes and campaign output that Claude Code reads before doing GTM work. See `CLAUDE.md` for how the folders and rules work, and `weekly-priorities/` for what is in progress.
